# 06-08-2026

## Event registration — email shown as a default question

When setting up registration questions for an event, organizers can now see that email is already collected — so they are less likely to add it again as a custom question.

- **Registration Questions (event form):** a fixed **Email** row appears at the top, above the phone number toggle
- The row shows that email is always collected and required for registration
- The toggle is on and cannot be changed — email collection is not optional
- **Collect Phone Number** and custom questions work the same as before

## Transactional emails — cleaner design and community sender

Event and community emails now look more like a polished invite (simple layout, clear typography, less filler text) instead of generic automated messages.

- **All transactional emails** (registration, invites, reminders, updates, announcements, etc.) use the same minimal style: event or community name up front, only the details that matter, one clear action button
- **Footer** still shows Luhive as the platform; the body no longer repeats marketing-style copy or emoji labels
- **Sender name:** emails arrive as the **community** (e.g. your community’s name in the inbox), not “Luhive” — Luhive stays visible only in the footer as the mediator
- **Announcements** keep their title, image, and description layout; styling matches the rest of the system
